1. What is DSA?

DSA stands for Data Structures and Algorithms. It is used to store, organize and process data efficiently.

2. Abstract Data Type (ADT)

ADT is a logical description of data and operations that can be performed on it.

3. Arrays

An array stores multiple elements of the same type in continuous memory locations. 

int marks[5] = {70, 80, 65, 90, 75};

4. Searching

  • Linear Search
  • Binary Search
  • Fibonacci Search

5. Sorting

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort

6. Time Complexity

Time complexity describes how the running time of an algorithm changes according to the input size.

  • O(1) - Constant
  • O(n) - Linear
  • O(log n) - Logarithmic
  • O(n²) - Quadratic

7. Stack and Queue

Stack: Follows LIFO - Last In First Out.

Queue: Follows FIFO - First In First Out.
