💻 C++ Programming Notes

Learn C++ from Basics to Object-Oriented Programming

1. Introduction to C++

C++ is a general-purpose programming language developed by Bjarne Stroustrup.

It supports procedural programming, object-oriented programming and generic programming.

2. Basic Structure of C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World";

    return 0;
}

#include <iostream> is used for input and output.

main() is the starting point of a C++ program.

3. Variables

A variable is a named memory location used to store data. 

int age = 20;
float marks = 85.5;
char grade = 'A';

4. Data Types

  • int – Integer values
  • float – Decimal values
  • double – Large decimal values
  • char – Single character
  • bool – True or False
  • string – Collection of characters

5. Input and Output

cin is used to take input from the user.

cout is used to display output. 

int age;

cout << "Enter age: ";
cin >> age;

cout << "Age = " << age;

6. Operators

  • Arithmetic: +, -, *, /, %
  • Relational: >, <, ==, !=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=

7. If-Else Statement

The if-else statement is used for decision making. 

int marks = 75;

if (marks >= 40)
{
    cout << "PASS";
}
else
{
    cout << "FAIL";
}

8. Loops

Loops are used to execute a block of code repeatedly.

For Loop

for(int i = 1; i <= 5; i++)
{
    cout << i << endl;
}

9. Functions

A function is a block of code designed to perform a specific task. 

int add(int a, int b)
{
    return a + b;
}

10. Object-Oriented Programming

C++ supports Object-Oriented Programming (OOP).

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

11. Class and Object

class Student
{
public:

    string name;

    void show()
    {
        cout << name;
    }
};

int main()
{
    Student s;

    s.name = "Shubhangi";

    s.show();

    return 0;
}
