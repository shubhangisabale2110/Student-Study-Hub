1. What is DBMS?

DBMS stands for Database Management System. It is software used to create, store, manage and retrieve data from databases.

2. Database

A database is an organized collection of related data.

3. Keys

  • Primary Key
  • Foreign Key
  • Candidate Key
  • Super Key
  • Alternate Key

4. SQL

SQL stands for Structured Query Language.

CREATE TABLE Student (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    marks INT
);

5. SQL Commands

  • CREATE
  • INSERT
  • SELECT
  • UPDATE
  • DELETE

6. Normalization

Normalization is the process of organizing data to reduce data redundancy and improve data integrity.

7. ER Diagram

ER diagram represents entities, attributes and relationships in a database system.
