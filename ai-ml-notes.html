Artificial Intelligence and Machine Learning

← Back to Study Hub

1. What is Artificial Intelligence?

Artificial Intelligence is a branch of computer science that enables machines to perform tasks that normally require human intelligence.

2. What is Machine Learning?

Machine Learning is a part of AI where computers learn patterns from data and make predictions or decisions.

3. Types of Machine Learning

  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning

4. Supervised Learning

In supervised learning, the model learns from labelled data.

Examples:

  • Linear Regression
  • Decision Tree
  • Classification

5. Unsupervised Learning

Unsupervised learning works with data without predefined labels.

Example: Clustering

6. Machine Learning Applications

  • Recommendation Systems
  • Face Recognition
  • Fraud Detection
  • Chatbots
  • Medical Diagnosis
  • Self Driving Cars
